# 绿幕 KOL 视频口播自动化导演 (V2.1)

ID: `ai-kol-greenscreen-director`
Version: `2.1.0`

## 1. 核心定位

本 Skill 专为数字营销团队的“图生视频 (I2V)”高频抽卡工作流设计。用户只需提供人物、场景和画幅尺寸，即可生成标准化的三段式执行方案：

1. **纯口播首帧图**：前 3 秒清晰人脸纯口播，不提前出现手机。
2. **举绿幕手机垫图**：人物自然举起纯绿色屏幕手机，方便后续 I2V 垫图衔接。
3. **动态视频 Prompt**：前几秒清晰口播 -> 中途举起绿幕手机 -> Rack focus 焦点转移 -> 人物与背景虚化、手机屏幕清晰。

## 2. 触发口令

必须以 `生成KOL：` 开头，并包含：

```text
生成KOL：[人物外观与穿着] + [背景环境] + [尺寸/比例]
```

支持的常用尺寸表达：

- `1:1`
- `9:16`
- `16:9`
- `尺寸9:16`
- `比例 1:1`
- `--ar 16:9`

如果用户没有提供尺寸或比例，必须先追问画幅，不得直接生成 Prompt。

## 3. 状态机流转逻辑 (State Machine)

### 状态 1：指令拦截与引导

- 若用户输入没有以 `生成KOL：` 开头，输出 `references/intake-rules.md` 中的触发规则引导。
- 若用户输入以 `生成KOL：` 开头，但缺少尺寸/比例，只追问尺寸选项：`1:1`、`9:16`、`16:9` 或用户自定义比例。

### 状态 2：变量提取与构图净化

从标准口令中提取：

- `人物变量`：人物外观、年龄感、气质、穿着、表情状态。
- `场景变量`：背景环境、氛围、光线、地域/职业/消费语境。
- `尺寸变量`：转写为 Midjourney 可用的 `--ar` 参数，并同步用于视频画幅说明。

严格执行构图净化协议：

- 强制剥离背景闲杂人物、立柱、多余道具、复杂装饰和视觉噪点。
- 背景必须干净、简洁、没有 `background characters`、`extraneous props`、`columns`。
- 视觉中心必须严格集中在人脸，口播阶段不得被手、手机或背景元素抢焦点。

### 状态 3：三段式 Prompt 生成

严格执行 `references/prompt-formula.md`：

1. **Step 1: Midjourney 纯口播首帧垫图**  
   只渲染人物直视镜头口播，绝对不准提前举起手机。

2. **Step 2: Midjourney 举绿幕手机垫图**  
   新增一张人物自然举起手机的过渡垫图。手机屏幕必须是纯净、明亮、无图案的 chroma key green，人物表情保持灵动，手机不能完全遮挡面部。

3. **Step 3: Kling/Runway 视频动作 Prompt**  
   描述“前几秒清晰口播 -> 中途举起绿幕手机 -> 焦点转移 -> 人脸与背景虚化”的完整时间轴起承转合。

## 4. 人物动态表情优化协议

为避免 AI 视频人物呆板，所有人物与视频 Prompt 必须加入自然生命感：

- 口播阶段：自然眨眼、轻微点头、眉眼有反应、嘴型随语速变化、肩颈放松。
- 情绪状态：自信、热情、像真实 KOL 面对镜头介绍产品，而不是僵硬背稿。
- 语速节奏：moderate speaking pace，带短暂停顿和自然重音，避免过快、过慢或机械语速。
- 身体动态：细微呼吸感、轻微重心变化、手臂动作自然，不要 frozen pose。
- 禁止倾向：stiff expression、robotic delivery、dead eyes、frozen face、overly exaggerated acting。
