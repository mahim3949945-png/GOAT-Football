# 绿幕 KOL 视频口播自动化导演 (V2.3)

ID: `ai-kol-greenscreen-director`
Version: `2.3.0`

## 1. 核心定位

本 Skill 专为中东地区足球资讯 App 买量广告的“图生视频 (I2V)”高频抽卡工作流设计。用户提供人物、场景、画幅尺寸、视频时长和 App logo 后，即可生成标准化的四模块执行方案：

1. **纯口播首帧图**：前 3 秒清晰人脸纯口播，不提前出现手机，并自然带入用户发送的 App logo。
2. **举绿幕手机垫图**：人物自然举起纯绿色屏幕手机，画面中继续带入 App logo，方便后续 I2V 垫图衔接。
3. **动态视频 Prompt**：前几秒清晰口播 -> 中途举起绿幕手机 -> Rack focus 焦点转移 -> 人物与背景虚化、手机屏幕清晰。
4. **足球 App 口播稿**：围绕中东足球用户痛点，介绍赛前首发阵容、阵型分析、赛中/赛后事件状态，以及球队/联赛关注能力。
5. **本地桌面归档**：默认把每次生成的导演方案、Prompt、口播稿和后续导出的素材保存到本地桌面文件夹。

## 2. 触发口令

必须以 `生成KOL：` 开头，并包含：

```text
生成KOL：[人物外观与穿着] + [背景环境] + [尺寸/比例] + [15秒/30秒]
```

支持的常用尺寸表达：

- `1:1`
- `9:16`
- `16:9`
- `尺寸9:16`
- `比例 1:1`
- `--ar 16:9`

如果用户没有提供尺寸或比例，必须先追问画幅，不得直接生成 Prompt。

支持的视频时长表达：

- `15秒`
- `30秒`
- `15s`
- `30s`

如果用户没有提供视频时长，必须先追问是生成 `15秒` 还是 `30秒`，不得直接生成 Prompt。

用户开始会随指令发送 App logo。若检测到 logo 附件，必须把 logo 作为图像参考带入 Step 1 与 Step 2 两张垫图；若没有检测到 logo，必须先提示用户上传 App logo，或确认本次不使用 logo。

## 3. 状态机流转逻辑 (State Machine)

### 状态 1：指令拦截与引导

- 若用户输入没有以 `生成KOL：` 开头，输出 `references/intake-rules.md` 中的触发规则引导。
- 若用户输入以 `生成KOL：` 开头，但缺少尺寸/比例，只追问尺寸选项：`1:1`、`9:16`、`16:9` 或用户自定义比例。
- 若用户输入以 `生成KOL：` 开头，但缺少视频时长，只追问：`请问本次视频要生成 15 秒还是 30 秒？`
- 若用户没有提供 App logo 附件，只追问：`请上传足球 App logo，或确认本次不使用 logo。`

### 状态 2：变量提取与构图净化

从标准口令中提取：

- `人物变量`：人物外观、年龄感、气质、穿着、表情状态。
- `场景变量`：背景环境、氛围、光线、地域/职业/消费语境。
- `尺寸变量`：转写为 Midjourney 可用的 `--ar` 参数，并同步用于视频画幅说明。
- `时长变量`：限定为 `15秒` 或 `30秒`，用于控制视频口播节奏与脚本文案长度。
- `Logo 变量`：用户上传的 App logo 图像引用，用于 Step 1 与 Step 2 垫图中的品牌露出。

严格执行构图净化协议：

- 强制剥离背景闲杂人物、立柱、多余道具、复杂装饰和视觉噪点。
- 背景必须干净、简洁、没有 `background characters`、`extraneous props`、`columns`。
- 视觉中心必须严格集中在人脸，口播阶段不得被手、手机或背景元素抢焦点。

### 状态 3：Prompt 与口播稿生成

严格执行 `references/prompt-formula.md`：

1. **Step 1: Midjourney 纯口播首帧垫图**  
   只渲染人物直视镜头口播，绝对不准提前举起手机。

2. **Step 2: Midjourney 举绿幕手机垫图**  
   新增一张人物自然举起手机的过渡垫图。手机屏幕必须是纯净、明亮、无图案的 chroma key green，人物表情保持灵动，手机不能完全遮挡面部。

3. **Step 3: Kling/Runway 视频动作 Prompt**  
   描述“前几秒清晰口播 -> 中途举起绿幕手机 -> 焦点转移 -> 人脸与背景虚化”的完整时间轴起承转合。

4. **足球资讯 App 口播稿**  
   根据 `15秒` 或 `30秒` 生成中东足球 App 推广口播。卖点必须包括：赛前首发阵容、阵型分析、实时事件状态 `END`、`Delayed`、`ABD`、`CAN`，以及最多关注 5 支球队和 5 项赛事、定制个人比分首页。

5. **本地桌面归档**  
   严格执行 `references/export-rules.md`。默认把完整导演方案保存为 Markdown 文件到 `~/Desktop/ai-kol-greenscreen-director/`；若运行环境没有桌面目录，则创建该目录或询问用户指定保存路径。若后续生成实际图片/视频文件，也保存到同一个项目子文件夹。

## 4. 人物动态表情优化协议

为避免 AI 视频人物呆板，所有人物与视频 Prompt 必须加入自然生命感：

- 口播阶段：自然眨眼、轻微点头、眉眼有反应、嘴型随语速变化、肩颈放松。
- 情绪状态：自信、热情、像真实 KOL 面对镜头介绍产品，而不是僵硬背稿。
- 语速节奏：moderate speaking pace，带短暂停顿和自然重音，避免过快、过慢或机械语速。
- 身体动态：细微呼吸感、轻微重心变化、手臂动作自然，不要 frozen pose。
- 禁止倾向：stiff expression、robotic delivery、dead eyes、frozen face、overly exaggerated acting。
