# 触发规则与错误引导

🎬 **AI 绿幕 KOL 导演 V2.2 已就位，等待您的抽卡指令！**

本工作流采用 **先定首帧图 -> 再生成拿手机展示图 -> 后生成动态视频** 的三段策略，用来精准控制：

- 前 3 秒：人物清晰人脸、直视镜头、纯口播。
- 展示图：人物像真实 KOL 一样灵动口播，同时自然拿着纯绿幕手机。
- 视频中段：人物突然举起一台纯绿幕手机。
- 视频结尾：镜头焦点从人脸转移到手机屏幕，人物与背景自然虚化。

输出会主动增强真人感，避免僵硬模特、蜡像感和证件照式表情。

## 正确指令格式

```text
生成KOL：[人物外观与穿着] + [背景环境]
```

## 示例

```text
生成KOL：穿着皇马球衣的中东年轻帅哥 + 极具科技感的电竞房
```

```text
生成KOL：穿着白色西装的东南亚女性创业者 + 高端现代办公室
```

```text
生成KOL：穿着黑色运动夹克的拉美健身教练 + 干净明亮的健身房角落
```

## 输入要求

- 必须以 `生成KOL：` 或 `生成KOL:` 开头。
- 必须包含人物描述。
- 必须包含背景环境。
- 人物与背景之间必须使用 `+` 分隔。
