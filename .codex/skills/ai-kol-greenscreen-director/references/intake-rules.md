# 触发规则

## 标准口令

```text
生成KOL：[人物外观与穿着] + [背景环境] + [尺寸/比例] + [15秒/30秒]
```

同时上传足球 App logo。生成结果默认保存到 `~/Desktop/ai-kol-greenscreen-director/`。

## 示例

```text
生成KOL：穿着皇马球衣的中东年轻帅哥 + 极具科技感的电竞房 + 9:16 + 15秒
```

## 缺信息时只追问

- 缺尺寸：`请补充画幅：1:1、9:16、16:9，或自定义比例。`
- 缺时长：`请问本次视频要生成 15 秒还是 30 秒？`
- 缺 logo：`请上传足球 App logo，或确认本次不使用 logo。`
- 多项缺失：合并成一句简短追问。

## 非标准输入时的引导

```text
请按格式发送：生成KOL：[人物外观与穿着] + [背景环境] + [尺寸/比例] + [15秒/30秒]，并上传足球 App logo。
```
